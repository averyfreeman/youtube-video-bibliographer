## GNOME Users Looking for Native GTK Applications for Simple Image Annotation

As a GNOME user, you may be searching for native GTK applications to annotate images. Fortunately, there are several options available that cater to different needs and preferences.

### Top GTK Native Annotation Tools

When it comes to annotating screenshots, several tools stand out for their features and ease of use. Some of the top options include:

*   **Gradia**: A modern GTK4/Libadwaita app designed specifically for annotating screenshots. It features ten annotation modes, including text overlays, arrows, rectangles, circles, a highlighter, and a redact/censor feature. A unique feature is the ability to add decorative backgrounds, such as gradients or solid colors, to screenshots for a professional look.
*   **Annotator**: Originally designed for elementary OS, this tool is built with GTK4 and works well across Linux distributions. It offers specialized tools for creating arrows, shapes, and sequence numbers (steps), which are highly useful for tutorials. It also includes features for magnifying sections of an image and blurring sensitive information.
*   **Drawing**: A simple image editor similar to Microsoft Paint designed for the GNOME desktop. While it is a general editor, it is frequently used for quick screenshot annotations like drawing boxes or arrows.
*   **Satty**: A lightweight annotation tool built with GTK4 and Libadwaita. It is often recommended as a modern alternative for users in Wayland environments who need quick markup capabilities.

Its specialized tools make it an excellent choice for creating tutorials and annotated screenshots.
